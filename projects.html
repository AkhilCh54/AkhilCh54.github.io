PROJECT 13 Ongoing
Building High-Confidence Copia Transposable Element Reference Library in the Aspidoscelis tesselatus
May 2026

Builds a manually curated LTR/Copia reference library by identifying genomic copies, refining sequence alignments, defining element boundaries, and generating representative consensus sequences.

Bioinformatics Transposable Elements LTR/Copia Sequence Analysis

This project focuses on developing a high-confidence reference library for LTR/Copia transposable elements from the marmoratus–maternal subgenome of Aspidoscelis tesselatus. Candidate families identified by RepeatModeler2 are manually curated by recovering homologous genomic copies with BLAST, generating multiple sequence alignments with MAFFT and T-Coffee, and inspecting alignments to remove poorly supported regions, refine element boundaries, and distinguish related sequence groups. Final representative consensus sequences are evaluated using structural analyses including TE-Aid and self-dotplots, and profile HMMs are generated from curated alignments. The resulting reference library provides high-quality TE sequences for genome annotation and can serve as a benchmark for evaluating automated and AI-assisted transposable-element identification pipelines.

PROJECT 12Ongoing
Exploring Uncharacterized Transposable Element Families Using Machine Learning
January 2026

Groups unclassified transposable elements into biologically meaningful clusters using sequence-derived features and unsupervised learning.

Python Bioinformatics UMAP Spectral Clustering

An ongoing bioinformatics project that characterizes unknown transposable element sequences from squamate reptile genomes. The pipeline extracts metadata, sequence composition, complexity, open reading frame, and k-mer features; standardizes the resulting feature matrix; creates a two-dimensional UMAP embedding; and applies spectral clustering to identify candidate TE families. The current best run produced three clusters with a silhouette score of 0.4005 and a Davies-Bouldin score of 0.7352, with UMAP scatter plots and feature-level box plots used to interpret the groups.

What Makes a Movie a Blockbuster?

Python Scikit-learn Data Mining Pandas

A group data mining project that asks: what separates a blockbuster from the rest? We defined "blockbuster" two ways — top 25% by revenue and top 25% by popularity — then trained parallel Decision Tree, Random Forest, Logistic Regression, and KNN classifiers on each.
